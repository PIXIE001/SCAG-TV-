# SCAG LIVE TV — AI NEWS STUDIO

Professional AI virtual newsroom system for SCAG LIVE TV.

## CORE PRINCIPLE

ORIGINALITY FIRST.

The uploaded presenter should remain the original presenter.

The system should preserve:

- Face
- Voice
- Clothing
- Expressions
- Gestures
- Body movement
- Head movement
- Timing
- Original audio

The AI changes the environment around the presenter.
